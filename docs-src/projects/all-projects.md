# All projects

This is where your organization starts. It leads to the **Sessions** or **Issues** tab you used last, across all your projects.

## What you see

- **With projects** — tabs for Sessions and Issues that cover every project at once.
- **No projects yet** — a short note, and a button.
  - **Connect GitHub** shows if GitHub is not connected and you are an admin.
  - **Choose repositories on GitHub** shows if GitHub is connected.
  - If you are not an admin, the note says an admin has to connect GitHub.

![All projects, empty, with Connect GitHub](shots/all-projects-1.png)

## Good to know

- A project is a GitHub repository the Hadji app can see. See [Add a project](/docs/projects/add-project/).
- Archived repositories are not listed. GitHub makes them read-only, so Hadji cannot run work in them.
- You only see projects you have access to.
