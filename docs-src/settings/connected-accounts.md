# Connected accounts

You sign in to Hadji with Google. Hadji does not know who you are on GitHub until you say so. Open **Settings → Connected accounts** to connect.

![Connected accounts](shots/connected-accounts-1.png)

## GitHub

Connect GitHub so sessions can open pull requests **as you**. After you sign in on GitHub you come back to this page, and it says how it went.

## Claude and Codex

Connect the agent accounts your sessions bill to. A connected subscription shows **subscription connected**. Without one, a session may show **using the workspace key**. If an admin has turned personal credentials off, the page says so.

## Good to know

- These are only yours, and only in this organization.
- Old links to the Profile page end up here.
