# GitHub

Open **Settings → GitHub** under **Workspace**. It reaches everyone in the organization. It says where your projects come from.

![GitHub settings](shots/github-1.png)

## The connection

The page names the GitHub account the Hadji app is installed on. Admins also get a link to GitHub, to change which repositories the app can see. Each repository the app can see becomes a project. See [Add a project](/docs/projects/add-project/).

## Hidden projects

Admins can remove a project from the console, and bring it back. The hidden ones are listed here with a way to restore them.

## Your own GitHub account

This page is about the organization. To let sessions open pull requests as you, connect your account in [Connected accounts](/docs/settings/connected-accounts/).
