# AI models and agents

Open **Settings → AI models & agents**. Everything here is only for you. An admin sets the workspace defaults in [Models and costs](/docs/settings/models-costs/).

![AI models and agents](shots/ai-models-agents-1.png)

## Model for new sessions

The model a new session starts on. A session can change its own model from the button in its message box.

## What each size runs

Sessions come in three sizes:

- **Small** — quick checks. Session titles, and plain lookups.
- **Medium** — everyday work. Reading code and normal pull-request work.
- **Large** — hard problems. Your own sessions, and planning, review, hard debugging and merging.

Each size has a **Primary** (what sessions run on) and a **Backup** (for when the primary runs out). You can swap them.

## When your model runs out

Turn on **Use a backup model**. When a model hits its usage limit or starts billing usage credits, sessions on that size switch to the backup. Choose what happens to a reply cut off in the middle:

- **Re-run my message on the backup**, or
- **Stop and tell me** — the next message uses the backup.

You can also have sessions **switch back when the main model resets**.

## Agents

Your connected agent accounts. Connect more in [Connected accounts](/docs/settings/connected-accounts/).

## If you cannot change it

Controls read **Read only — your role cannot change this.**
