# Using the phone app

> Check sessions, answer questions, see issues and deploys from your phone.

# Using the phone app

The phone app is a lighter view of Hadji at `/m`. Install it first: [Install the phone app](/docs/phone/install/).

![Phone app home](https://hadji.ai/docs/media/shots/phone-app-1.png)

## What you can do

- **Home** opens on the last organization you used. Switch organizations from the organization sheet.
- **See sessions** and which ones wait on you. The count shows on the app icon.
- **Open a session**, read it, and reply with the phone's message box. A model button and a send menu are there too.
- **Open a project** to see its sessions, issues and deploys.
- **Start a new session** in a project.
- **Settings** has notification controls and a default model.

## When you need the desktop

Some things are not on the phone. Deploying needs the Hadji engine, and a banner can offer **Open on the desktop console**.

## Notifications

You get a ping when a session needs you, or finishes one you follow. See [Install the phone app](/docs/phone/install/) if you get none.
