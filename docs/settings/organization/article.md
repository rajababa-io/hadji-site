# Organization settings

Open **Settings → Organization** under **Workspace**. Everyone can read it. Owners and admins change it.

![Organization settings](https://hadji.ai/docs/media/shots/organization-1.png)

- **Name and address** — the org's name and the address in the URL.
- **Logo** — the organization's logo.
- **Accent color** — the color the console uses for the org. A person's own accent color wins over it.
