Guide for database owners

Connect your database to Hadji.

About 15 minutes. No open ports, no address to allowlist, no Cloudflare account needed. Your Hadji contact gives you one install command with your own key in it. You run it next to your database. That is all.
~15 minutesNo open portsNo address to allowlistNo Cloudflare account

How it works

Your small connector program and Hadji both dial out to Cloudflare. They meet in the middle. Nothing connects into your network, so your firewall stays closed.

  1. Make a read-only user Create a login that can only read, ideally on a read-only replica (a copy of the database). Change the name, password and database below. 
    CREATE LOGIN hadji_readonly WITH PASSWORD = 'choose-a-long-random-password';
USE YourDatabase;
CREATE USER hadji_readonly FOR LOGIN hadji_readonly;
ALTER ROLE db_datareader ADD MEMBER hadji_readonly;
    CREATE ROLE hadji_readonly LOGIN PASSWORD 'choose-a-long-random-password';
GRANT CONNECT ON DATABASE yourdatabase TO hadji_readonly;
GRANT USAGE ON SCHEMA public TO hadji_readonly;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO hadji_readonly;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT ON TABLES TO hadji_readonly;
    CREATE USER 'hadji_readonly'@'%' IDENTIFIED BY 'choose-a-long-random-password';
GRANT SELECT ON yourdatabase.* TO 'hadji_readonly'@'%';
FLUSH PRIVILEGES;
    Using other schemas? Repeat the grant for each one. The user must not be able to write, drop or change anything.
  2. Pick a machine next to the database Any small server in your network that can reach the database will do. It needs outbound internet only: no inbound rules. Allow outbound traffic to Cloudflare on port 7844 (TCP and UDP). Port 443 is not a substitute — Cloudflare lists it only for optional extras like update checks.
  3. Install the connector Your Hadji contact sends you this command with your own key in it. Keep the key private. Replace <your key> below with it. The connector runs as a service and restarts after a reboot. 
    # Debian or Ubuntu: add Cloudflare's package repository, then install
sudo mkdir -p --mode=0755 /usr/share/keyrings
curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
echo 'deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main' | sudo tee /etc/apt/sources.list.d/cloudflared.list
sudo apt-get update && sudo apt-get install cloudflared

# Red Hat, CentOS, Amazon Linux: use these two lines instead
# curl -fsSL https://pkg.cloudflare.com/cloudflared.repo | sudo tee /etc/yum.repos.d/cloudflared.repo
# sudo yum update && sudo yum install cloudflared

# Start the connector as a service
sudo cloudflared service install <your key>
    # In an Administrator PowerShell, after installing cloudflared from
# https://github.com/cloudflare/cloudflared/releases/latest (cloudflared-windows-amd64.msi)
cloudflared.exe service install <your key>
    docker run -d --restart unless-stopped cloudflare/cloudflared:latest tunnel --no-autoupdate run --token <your key>
    // Task definition: store the key in AWS Secrets Manager, not in the file

// Run it as an ECS service with desired count 1 so it restarts if it stops.
  4. Send the read-only login to your Hadji contact Share it through a private channel such as a password manager. Never plain email. They need the host, port, database name, user name and password.
  5. Check it worked On Linux, run the first command and look for Registered tunnel connection. Your Hadji contact will see "Connector online". 
    sudo journalctl -u cloudflared --no-pager | tail -n 20
  6. Cut access any time Stop the service and access ends at once. To remove it for good, uninstall it. 
    sudo systemctl stop cloudflared
sudo cloudflared service uninstall
    On Windows run cloudflared.exe service uninstall. On Docker, run docker stop on the container.
