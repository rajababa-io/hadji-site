Start your first job

Describe the problem in plain words. Hadji plans it, builds it and tests it.

Recorded from Hadji v0.42 on Nov 2 · 3 steps · about 3 minutes

Screen recordingStart your first job0:00 / 0:15

1Pick the project

Choose a project in the left list. Each one is an app or site Hadji works on.

2Describe the job

Say what is wrong or what you want, the way you would tell a colleague. Example: "Customers say the checkout total is a cent off with a coupon."

3Watch it work

Hadji lists its steps and ticks them off. You can leave. It tells you when it needs you.

Rather not click through it? Ask Hadji to do it for you — type what you want in the chat and it does the steps. Ask Hadji →
