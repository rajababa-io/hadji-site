Start a session from an issue

Turn one or more issues into sessions from the board.

Updated Nov 2 · about 1 minutes

  1. Open the Issues board.
  2. Right-click the card, or select several cards.
  3. Choose Start session. For several cards you can choose Start N sessions, or Start 1 session for all.
  4. Hadji says how many sessions started. They are in the Sessions tab.

Good to know

  • A session runs in one project. Start 1 session for all only shows when every card is in the same project.
  • The issue number shows in the session's title. That ties the session and the issue together on the board.
  • You need the Member role or higher. Viewers cannot start sessions.
