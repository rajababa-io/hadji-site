# The Sessions tab

Sessions are where you work with agents. The list is on the left. The open session is on the right.

![Sessions tab](https://hadji.ai/docs/media/shots/using-sessions-1.png)

## Send a message

- Type in the message box. Press **Enter** to send.
- While the agent works, **Enter** queues your message. It is sent when the agent finishes.
- Press **Esc** to stop the agent.
- Drop files or paste an image to attach it.
- Type **/** to open a menu of commands and skills.
- If the agent has a question above, press **↑** to answer it.

## Pick a model

The button in the message box changes the model for this session. Your default for new sessions is in [AI models and agents](/docs/settings/ai-models-agents/).

## See what a session is doing

- The dot beside each session shows its state. See [What the colors mean](/docs/sessions/status-colours/).
- **Session details** shows where it runs, its branch, how many files changed, and its pull request. It has an **Open in Deploy** link.
- It also shows how full the session's memory is, and what it has cost. See [Cost and context](/docs/sessions/cost-and-context/).

## When you cannot type

- **Viewers** see no message box and no New session button. A project admin has set your role on this project to Viewer. Ask them to lift it. See [Members and roles](/docs/settings/members-roles/).
- **Archived repositories** are read-only. Nothing can run.
- A session may be **locked** until someone acts. See [Questions and approvals](/docs/sessions/questions-and-approvals/).
