Ask about a session without interrupting it

The side chat answers questions about a session while the agent keeps working.

Updated Nov 2 · about 1 minutes

Use the side chat when you want to know what a session is doing, but do not want to distract the agent.

Open it

  • Click Side chat in the header, or press Ctrl ; (works from anywhere, even while typing).
  • It is on desktop only.

Ask

  1. Type your question and send it.
  2. Hadji reads the session's transcript and answers using the session's model.

What to know

  • Nothing is added to the session. The agent never sees your question or the answer. It keeps working.
  • It is forgotten when you close it. Closing the panel, or opening another session, clears it. Esc closes it.
  • It costs a little. Each answer counts in the session's cost. See Cost and context.
  • To change what the agent does, use the normal message box instead.
