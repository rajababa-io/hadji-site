# Add a project

A Hadji project is a GitHub repository that the Hadji app can see. So adding a project means letting the app see one more repository. That choice is made on GitHub.

## Steps

1. In the left rail, click **Add project**.
2. Click **Choose on GitHub**. GitHub opens in a new tab.
3. Pick the repositories you want to allow, and save.
4. Go back to Hadji. The new project shows up a few seconds later. Nothing is copied until a session needs it.

![Add project dialog](https://hadji.ai/docs/media/shots/add-project-1.png)

## If it does not show up

Click **Refresh the list** in the dialog. Hadji asks GitHub again. If it says "Try again in a few seconds", wait and click again.

## If you are not an admin

You see no GitHub button. Only an admin of the organization can let Hadji see another repository. The dialog tells you to ask one.

## If the org is not connected to GitHub yet

An admin connects it first, from [All projects](/docs/projects/all-projects/) or [GitHub settings](/docs/settings/github/).
