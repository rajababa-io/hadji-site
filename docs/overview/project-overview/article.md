# The project Overview

Opening a project lands you here. The old Code map tab now lives on this page too, so old links still work.

## What is on the page

- **What this project is** — pictures that sessions drew to explain the project. Shows only when there are some.
- **Where this project is** — the project's brief: why it exists, what is being worked on, and where it has got to. A pink pill says how many sessions wait on you, and links to Sessions.
- **Live code map** — a picture of the code and how its parts connect.
- **Pinned pictures, public links, handoffs** — in the column on the right. See [Pictures and handoffs](/docs/overview/pictures-and-handoffs/).

![Project Overview](https://hadji.ai/docs/media/shots/project-overview-1.png)

## The brief

The brief is written by the agents, not typed by you. They update it when a piece of work lands. The brief card has a refresh button if you want it brought up to date now.

## Archived repositories

If the repository is archived on GitHub, the project page says so. Nothing can run in it until you unarchive it on GitHub.
